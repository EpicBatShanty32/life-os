## v0.1.0 — первый рабочий контур (2026-11-16)

### Что это

Персональный Telegram-агент, который трижды в день сам пишет пользователю, подробно
расспрашивает про день, складывает ответы в Obsidian и собирает локальный дашборд.
Всё работает на Mac пользователя, без облака и без внешних библиотек.

### Что умеет

- **Telegram Bot API (long polling).** Один разрешённый `chat_id`, чужие игнорируются;
  текст до 4000 символов с разбивкой; 429 (`retry_after`), 409 (двойной запуск), 401 —
  обрабатываются, цикл не падает.
- **Три слота по Europe/Moscow:** 08:30 (план, 3 задачи, цели), 14:00 (еда, вода, энергия),
  21:30 (тренировка, задачи, еда за день, настроение/энергия/фокус, мысли). Догон
  опоздавшего слота — 180 минут, TTL сессии — 12 часов.
- **Диалог, а не анкета:** один вопрос за сообщение, до 2 уточнений при коротком ответе,
  «-»/«пропустить», «стоп», `/статус`. Свободный текст в любой момент — ответ + сохранение.
- **12 команд** с русскими алиасами: `/start`, `/status`, `/today`, `/report`, `/goals`,
  `/add_goal`, `/pause`, `/resume`, `/skip`, `/help`, `/дизайн` (+ `старт`, `статус`, …).
- **Obsidian:** daily `01 Daily/YYYY-MM-DD.md` из шаблона, разделы `## Еда (агент)` и др.,
  маркеры `<!-- lifeos:entry:ID -->` (без дублей), таблица целей между маркерами,
  зеркало `Life OS/data/entries.jsonl` + `goals.json`.
- **Дашборд:** один HTML-файл без CDN и интернета, 10 карточек (сегодня, KPI, цели, сон,
  тренировки, питание/вода, настроение/энергия, привычки, журнал, хитмап 8 недель),
  пересборка после каждой записи, пустые состояния без «NaN».
- **Установка:** `install.sh` → `~/Library/Application Support/LifeOS`, конфиг 600,
  LaunchAgent `com.lifeos.agent` (RunAtLoad + KeepAlive), подхват `DDD_API_KEY`,
  снятие карантина; `uninstall.sh` (данные сохраняются) и `--purge`.
- **LLM опционален:** SAMP `deepseek-v4.1-flash-1017`; при любом сбое — скриптованные
  вопросы и эвристика разбора, данные пишутся всегда.

### Установка

```bash
cd "/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent"
cp config/config.example.json config/config.json      # вписать token и allowed_chat_id
bash install.sh
open "$HOME/Library/Application Support/LifeOS/dashboard/index.html"
```

Подробно, по шагам и с лечением ошибок — `README.md` (324 строки).

### Известные проблемы

1. **Прогресс убывающих целей врёт.** «Похудеть до 78 кг» при текущем весе 78 показывает
   **100%** (формула `current/target` без направления). Данные верны, визуализация — нет.
   Обход: задавать прогресс явно (`/add_goal … | 3/10`). Фикс — `QUALITY_BACKLOG.md` #3.
2. **`weekly` выключен.** Недельный дайджест — фаза 2 (ТЗ §10), код слота есть,
   заметка `01 Daily/Неделя YYYY-Www.md` не создаётся.
3. **E2E не сдан.** `tests/e2e_mock.py` отсутствует; приёмочный п.2 ТЗ §8 не доказан.
4. **Живой запуск не проверен.** Токена нет; установка проверена только `--dry-run`
   и тестами (`tests/test_install.py`, 12 тестов).
5. **Ротация stdout-лога.** `RotatingFileHandler` крутит `data/logs/agent.log` (5 МБ × 3),
   но `~/Library/Logs/LifeOS/agent.log` от launchd растёт без ротации (backlog #4).
6. **Full Disk Access.** Запись в `~/Documents/…` может требовать ручного разрешения
   macOS (README §9); автопроверки нет (backlog #5).
7. **Браузерная проверка демо** не сделана: консольные ошибки и вид «как референс»
   не подтверждены (`UX_REVIEW.md` ожидается).

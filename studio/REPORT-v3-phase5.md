## Стек и каркас

React 19 + TypeScript + Vite, без UI-библиотек и CDN. 13 маршрутов в `lib/router.ts` (hash-роутер), `App.tsx` — каркас с сайдбаром, мобильной навигацией, ⌘K-палитрой и быстрой записью.

- **Sidebar 3.0** (`components/Sidebar.tsx`): 4 контура, сворачивание 260↔68 px (`tokens.css`), бейджи разделов, футер со статусом синка и переключателем темы (светлая/тёмная/авто), серия дней.
- **⌘K** — палитра команд (`CommandPalette.tsx`), **«+ Быстрая запись»** — `QuickEntryDialog.tsx` → `POST /api/quick`.
- **Мобильная навигация** (`MobileNav.tsx`) с бейджами и `aria-current`; сайдбар прячется на ≤900 px.
- **Доступность:** skip-link, `aria-label` у графиков, `prefers-reduced-motion` в `base.css` и `pages.css`, контраст по токенам.
- **Палитра владельца:** `#F6F7FB / #FFFFFF / #17181C / #7A7D87`, акценты `#A18BB7 / #AEDEC2 / #F2C9B6 / #B9CBE8`, радиусы 18–20, системные шрифты.

## Что осталось

- Восемь разделов живут на общем `SectionPage`; если понадобится глубже (например, отдельный календарь привычек) — это отдельная задача, данные и API уже есть.
- Демо-сидер даёт только слабые корреляции (r≈0,04) — ветки «связь есть» и прогноз с датой видны на синтетике в тестах, а не на демо-данных. Это честно отражено в UI словом «слабая связь».

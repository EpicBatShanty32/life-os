## 0. Автопроверка: как запускать и что она значит

```bash
cd /Users/user/Documents/deepseek-harness/default-workspace/life-os
python3 -m pytest app/tests/test_bot_acceptance.py -q          # быстрый прогон
```

Сеть не нужна: роутер собирается без ключа LLM, БД — во временном каталоге,
рабочий код бота тесты не меняют. Корпус идёт через актуальный роутер бота
(`app.bot.intent_v4`); отдельный тест `test_legacy_intent_still_works`
проверяет, что старый `app.bot.intent` (замеры/еда/тренировки) не сломан.

Что проверяют автотесты:

- смысл фразы: тип записи, ключевые поля, дата/время — не сравнение строк;
- допустимые варианты: `accept_actions`, `may_ask` (честный вопрос), даты в
  нескольких форматах;
- «ничего не теряется»: молчаливого «не понял» нет; нераспознанное уходит в
  Инбокс с исходным текстом;
- однозначные фразы не задают лишних вопросов (`may_ask=False`);
- обработчик: подтверждение одной строкой с типом, без эмодзи, чужой чат
  игнорируется, еда v3 пишется в `food_log`, команды без контекста честно
  отвечают, владелец один;
- v3-совместимость: вес/вода/сон/жим/еда/тренировка/настроение.

Если бот чего-то не умеет: тест падает с фразой и ожиданием. Если фича
известна как незавершённая — id добавляется в `KNOWN_GAPS` в `corpus.py` с
причиной, и тест помечается `xfail`; когда фича появляется, тест печатает
предупреждение «уберите id из KNOWN_GAPS». Так список не зарастает.

## 2. Чек-лист на телефоне (t30)

**Подготовка**

- [ ] Бот запущен как служба (t24): после перезагрузки мака отвечает.
  Токен не в логах, чужой чат молчит.
- [ ] Для приёмки — **копия базы** и отдельный бот/токен, чтобы не засорять
  реальные записи владельца. Если копии нет — после каждого шага удалять
  тестовую запись кнопкой «Удалить» и фиксировать это в отчёте.
- [ ] Телефон: Telegram, чат с ботом; веб открыт рядом (`http://127.0.0.1:8790`
  или живой 8787) на вкладках «Дела/Финансы/Питание/Библиотека/Личное/Инбокс».
- [ ] Каждый шаг: скриншот ответа бота + скриншот веба (или запись экрана).

**Шаг 1. Старт и клавиатура**

- [ ] `/start` → короткое приветствие, без эмодзи и простыней.
- [ ] Внизу постоянная клавиатура: **Дело · Расход · Еда · Привычка · Мысль · Сводка**.
- [ ] Нажатие «Дело» присылает подсказку-пример, а не пустоту.

**Шаг 2. Пять типов за минуту (BOT-MAIN §6.1)**

| Написать | Ожидаемый ответ (одна строка, с типом) | Проверить в вебе |
|---|---|---|
| `завтра позвонить в банк` | «Записал дело: «Позвонить в банк» — завтра, …, важно» | Дела → завтра, сфера |
| `такси 450` | «Записал расход: 450 ₽ — Транспорт, …» | Финансы → транзакция 450 |
| `на обед гречка 200 г и курица 150` | «Записал еду: Гречка 200 г, Курица 150 г, обед» | Питание/дневник еды |
| `выпил 2 л` | «Привычка «Вода 2 литра» — сегодня · 2 л» | Личное → привычки/вода |
| `мысль: сон важнее продуктивности` | «Мысль в «Без книги»: …» | Журнал/мысль |

- [ ] Все пять подряд, без слэшей; каждая запись видна в вебе.

**Шаг 3. Даты, числа словами, опечатки**

- [ ] `в пятницу стоматолог в 15` → дело, пятница, 15:00.
- [ ] `15 числа оплатить интернет` → дело на 15-е.
- [ ] `потратил тысячу двести на такси` → расход 1200 ₽.
- [ ] `получил 50 тысяч за проект` → доход 50 000 ₽.
- [ ] `спал семь с половиной часов` → сон 7,5 ч.
- [ ] `звтра пазванить в банк` → дело «позвонить в банк» на завтра.
- [ ] `купил кафе 3 20` → расход 320 ₽ (кофе), не 3 ₽.

**Шаг 4. Ничего не теряется**

- [ ] `абракадабра блабла` → «Положил в инбокс, разберём», `inbox_items` +1
  с исходным текстом; в вебе запись в Инбоксе.
- [ ] То же для `qwerty asdf` и `хочу что-то но не знаю что`.
- [ ] Ни один ответ не содержит «не понял» без действия.

**Шаг 5. Правка последнего**

- [ ] `перенеси на завтра` → последнее дело/запись сдвинута, ответ с датой.
- [ ] `это в работу` → список «работа».
- [ ] `удали последнее` → запись исчезла и в боте, и в вебе (кнопка
  подтверждения).
- [ ] Кнопки под подтверждением «Изменить»/«Удалить» работают и не врут.

**Шаг 6. Еда и тело**

- [ ] `съел 600 ккал и 40 белка` → еда, ккал/белок.
- [ ] `вес 81.2, жир 18.5` → замер тела, оба числа.
- [ ] `вода 300` → 300 мл; `вода` → вопрос «сколько?» (или Инбокс, но не
  молчание).
- [ ] `энергия 3` → чек-ин энергии 3/5; `настроение 7` → 7/10.
- [ ] `отжался 3 подхода по 20` → тренировка, 3×20.

**Шаг 7. Библиотека, цели, привычки**

- [ ] `читаю Sapiens стр 120` → прогресс книги.
- [ ] `цитата: …` → цитата; `инсайт из книги: …` → инсайт.
- [ ] `дочитал Sapiens, 5 из 5` → книга done, оценка 5.
- [ ] `отложил книгу 1984` → полка «Отложено».
- [ ] `+10% к цели Здоровье` → прогресс цели; `веха выполнена` → веха.
- [ ] `не курил`, `пробежал 5 км`, `сделал зарядку` → привычки за сегодня.

**Шаг 8. Вопросы и команды**

- [ ] `/today`, `/week` → 3–6 строк фактов, без простыней.
- [ ] `сколько потратил за неделю` → сумма, совпадающая с вебом (Финансы).
- [ ] `что на сегодня`, `какие задачи на завтра`, `покажи книги`,
  `как я спал за неделю` → ответ из БД, **новых записей не создают**.
- [ ] `/backup` → файл базы приходит в чат и открывается (t28).
- [ ] `/stats`, `/help`, `/mute` — работают и не падают.

**Шаг 9. Голос, фото, документ**

- [ ] Голосовое 5–10 с → текст в ответе/записи; если расшифровка недоступна,
  честная подпись, файл не теряется.
- [ ] Фото еды/чека с подписью → запись дня + вложение.
- [ ] Документ → запись, файл доступен; лимит размера соблюдается.

**Шаг 10. Правила ответов**

- [ ] Каждое подтверждение — **одна строка**, содержит тип записи, при
  необходимости — дату/сумму.
- [ ] Эмодзи в ответах нет (в данных привычки — допустимы).
- [ ] Чужой аккаунт/чат получает молчание (бот однопользовательский).
- [ ] В ответах нет «сборка», версий и внутренних меток.

**Шаг 11. Веб видит всё, что внёс бот**

- [ ] Дело/расход/еда/привычка/мысль из шага 2 видны на своих экранах.
- [ ] Правка записи в вебе не расходится с ботом (бот не перезатирает).
- [ ] Инбокс разбирается: «в задачу/проект/личное/книгу/удалить» — элемент
  исчезает, сущность появляется.

**Шаг 12. Живучесть (t24/t28)**

- [ ] Перезагрузка мака → бот отвечает без ручного запуска.
- [ ] `launchctl`/лог: процесс жив, лог ротируется, токена в логе нет.
- [ ] Бэкап: `/backup` + восстановление на копии по инструкции — записи целы.

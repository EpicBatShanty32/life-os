# Life OS v3 — фаза 3: движок Obsidian и сидер

- **Статус:** готово
- **Дата:** 2026-11-17
- **Коммит волны:** c45bb2a / `4d093d9`
- **Требование:** MASTER_SPEC §2.1, волны `t9` (vault) и `t10` (сидер)

## Vault (`app/server/vault.py`, 1 256 строк)

- Идемпотентная запись `01 Daily/YYYY-MM-DD.md`: маркер `<!-- lifeos:entry:ID -->`, повторная запись обновляет блок, а не дублирует.
- Дневная заметка создаётся из шаблона `Шаблоны/Шаблон - День.md`; подстановки `{{date}}` и родственные.
- Таблица целей между маркерами, слияние YAML-frontmatter без потери ручных правок.
- Курсы: `Courses/<Курс>/<Урок>.md`; здоровье: `Health/*.md`; конспекты и таймкоды.
- Безопасность: `VaultPathError` на выход за пределы vault (`..`, симлинки), `VaultDisabledError` при выключенной записи, лимиты длины, санитайзинг маркеров и текста, атомарная запись.

## Сидер (`app/server/seeder.py`, 827 строк)

- 120 дней правдоподобных данных: вес 81.4 → 79.8 с шумом, сон 6.2–8.0 ч, вода, настроение, тренировки 3/нед.
- 2 демо-курса по 6 уроков с конспектами и 162 сегментами таймкодов.
- Детерминирован (`--seed 42`) и идемпотентен: повторный запуск не дублирует; `--reset` удаляет только демо.
- Пишет в отдельный файл (`data/lifeos-v3.db` по умолчанию, D-15), рабочую базу v0.x не трогает.

## Чем проверено

```text
python3 -m pytest app/tests/test_vault.py -q          # 60 passed
python3 -m pytest app/tests/test_seeder.py -q         # 30 passed
python3 -m app.server.seeder --db "$TMP/qa.db" --days 120 --seed 42
Засеяно за 120 дней: 824 метрики, 382 отметки привычек, 3 цели, 2 курса, 12 уроков, 162 сегмента
```

Проверено: повторный сид не меняет количество строк; маркеры не дублируются; ручная правка вне маркеров сохраняется; путь наружу vault даёт ошибку; запись атомарна.

## Что осталось

- Живая запись в личную базу Obsidian не выполнялась: по правилам сессии личные файлы не трогаем, тесты работают на временных vault'ах. Первая реальная запись произойдёт при запуске бота у владельца.

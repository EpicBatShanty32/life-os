# Бот — главный узел Life OS

Решение владельца (приоритет №1 от 2026-11-18): **всё вносится с телефона через Telegram-бота.
Веб — витрина для просмотра.** Это меняет приоритеты: бот важнее любых экранов.

Любой агент, который трогает `app/bot/**`, читает этот файл до начала работы.

## 1. Принципы

1. **Одно сообщение — одна запись.** Человек пишет как в переписке, бот сам раскладывает.
2. **Ничего не теряется.** Если фраза не распознана — запись всё равно сохраняется в «Инбокс»
   с исходным текстом, а бот отвечает: «Положил в инбокс, разберём». Молчаливого «не понял» нет.
3. **Всегда подтверждение в одну строку**: что именно, куда, на какую дату. Без простыней.
4. **Работает без интернета-ИИ.** Без ключа и без сети — правила: числа, даты, словари.
   ИИ только улучшает разбор, но не является условием работы.
5. **Голос и фото — полноправные входы.** Голос → текст → запись. Фото еды/чека — прикрепляется
   к записи дня. Распознавания содержимого не обещаем, пока его нет.
6. **Один владелец.** Первый, кто написал боту, становится единственным (`allowed_chat_id`).
   Чужим бот не отвечает вообще.
7. **Без эмодзи и без «ии-слопа».** Сухой человеческий русский, короткие строки, цифры.

## 2. Куда что пишется

| Фраза с телефона | Что создаётся |
|---|---|
| «завтра позвонить в банк», «в пятницу стоматолог в 15» | задача с датой/временем, сферой, проектом, приоритетом |
| «сделал», «готово», «закрыть созвон» | последняя подходящая задача закрывается |
| «перенеси на завтра», «это в работу» | сдвиг даты / смена статуса последней записи |
| «такси 450», «зарплата 120000», «кофе 320 наличными» | транзакция: сумма, категория, счёт, тип |
| «потратил тысячу двести на такси», «сколько за неделю» | то же / сводка цифрами |
| «читаю Sapiens стр 120», «цитата: …», «мысль: …» | книга/прогресс, цитата, инсайт |
| «энергия 4, устал после созвонов», «настроение 7» | чек-ин дня (энергия, настроение, заметка) |
| «выпил 2 л», «пробежал 5 км», «не курил» | отметка привычки за сегодня |
| «на обед гречка 200 и курица 150», «съел 600 ккал» | приём пищи с КБЖУ из справочника |
| «вес 81.2, жир 18.5», «спал 7.5» | замеры тела, сон |
| «+10% к цели Здоровье», «веха выполнена» | прогресс цели/вехи |
| «что на сегодня», «сколько потратил», «что читал про сон» | ответ из БД, 3–6 строк |
| «удали последнее» | удаление последней записи с подтверждением кнопкой |
| всё непонятное | «Инбокс», исходный текст сохранён |

## 3. Постоянная клавиатура

Внизу экрана всегда: **Дело · Расход · Еда · Привычка · Мысль · Сводка**.
Кнопка шлёт короткий запрос, человек дописывает детали. Слэш-команды — для тех, кто любит,
но запоминать их не нужно.

Команды для полноты: `/today`, `/week`, `/morning`, `/evening`, `/backup`, `/stats`, `/mute`, `/help`.

## 3.1. Напоминания и ритуалы (t27)

Бот начинает разговор сам — вебом для этого не пользуются.

| Когда | Что приходит | Кнопки |
|---|---|---|
| 09:00 | утренний ритуал: вес, сон, план дня | «Отложить 1 ч», «Пропустить» |
| 22:00 | вечерний итог: закрыто/расходы/еда/энергия + 3 вопроса | энергия 1–5, «Отложить 1 ч», «Пропустить» |
| за 30 мин до дела со временем | «Через 30 минут: «Стоматолог» — 15:00» | «Сделал», «Отложить 1 ч», «На завтра», «Пропустить» |
| 20:00 | привычки, которые не отмечены | «Отметить: …» по каждой, «Пропустить» |

Правила:

- **тихие часы 23:00–08:00** — ночью бот молчит; исключение — жёсткие события
  (`resource = 'must'`), которые владелец сам поставил на ночь;
- **не спамить**: на одно дело не больше 2 напоминаний в день, «Отложить 1 ч»
  сверх лимита честно отвечает «больше не напомню»;
- **мак был выключен** — пропущенное помечается `missed` и не догоняется;
  приходит только то, что актуально сейчас (у ритуала окно 90 минут, у дела —
  10 минут после начала);
- **кнопки пишут в БД**: «Сделал» закрывает дело (`done_at`), «На завтра»
  сдвигает дату и время, отметка привычки — `habit_marks`, энергия — чек-ин;
- **состояние переживает перезапуск**: события дня в таблице `reminder_events`,
  настройки — в `settings_kv` с префиксом `reminders.`;
- настраивается командами: `/reminders morning 08:30`, `evening 21:30`,
  `habits 19:30`, `lead 15`, `max 3`, `quiet 23:00-08:00`; выключить целиком —
  `/mute`, включить — `/unmute`. Ручной запуск — `/morning`, `/evening`.

## 4. Что веб делает, а что нет

- Веб **читает** всё, что внёс бот, и позволяет править/удалять на месте (не вводить заново).
- Настройки, справочник продуктов, импорт весов из CSV, статистика использования — веб.
- Дублирующих форм ввода в вебе не плодим: основной ввод — бот.

## 5. Живучесть (обязательно, иначе весь смысл теряется)

- Автозапуск через launchd, поднимается после перезагрузки мака.
- Мак не должен засыпать, пока бот нужен: `caffeinate`/`pmset` при питании от сети.
- Автобэкап базы и `/backup` — файл в Telegram по команде.
- Логи с ротацией, токен нигде не пишется.

## 6. Как понять, что бот стал главным узлом

1. Внести за минуту с телефона: дело, расход, еду, привычку, мысль — пять разных типов подряд,
   без единого слэша.
2. Любая фраза из корпуса QA (80+) даёт запись или честный вопрос, ничего не теряется.
3. Внёс в боте → открыл веб → увидел там же. Правки в вебе бот видит.
4. Утром и вечером бот сам пишет ритуал, кнопки под ним что-то меняют.
5. Вопрос «сколько потратил за неделю» получает верную цифру, а не отговорку.
6. Перезагрузка мака не ломает бота. Бэкап восстанавливается по инструкции.

## 1. Что это

Персональный AI-ассистент в Telegram, который несколько раз в день сам пишет пользователю,
подробно расспрашивает про жизнь (задачи, еда, вода, тренировки, сон, цели, состояние, мысли),
складывает ответы в Obsidian-базу пользователя и собирает локальный дашборд в браузере Mac.

Ключевая формула из ТЗ §1: **бот — не опросник, а внимательный собеседник**. Он задаёт
уточняющие вопросы, но не спамит и не читает мораль.

## 2. Цель и признак успеха

дашборд» на своём Mac без ручной сборки данных.

| вс 21:00 | `weekly` | итоги недели + вопросы на неделю вперёд | **выключен** (`config/config.example.json:40`), фаза 2 — ТЗ §10 |
| в любой момент | `free` | свободный текст → человеческий ответ + извлечение данных | категория по смыслу |

Правила диалога (ТЗ §3.2): один вопрос за сообщение; ответ <30 символов и вопрос требует
деталей → до 2 уточнений (`llm.max_followups`, `config/config.example.json`), дальше следующий
вопрос; «-»/«пропустить» — пропуск; «стоп» — прервать; `/статус` — состояние; пропущенный слот
насильно не догоняется, вечером — один мягкий пинг (окно догона 180 мин,
`src/scheduler.py:352`; TTL сессии 12 ч, `src/scheduler.py:510`).

## 5. Границы

**Входит в v0.1:** Telegram Bot API long polling (один разрешённый `chat_id`), 3 слота,
свободный чат, 12 команд с русскими алиасами, SQLite, Obsidian daily + цели + зеркало JSONL,
self-contained дашборд (10 карточек), install/uninstall + launchd, README, 148 тестов.

**Не входит (фаза 2, ТЗ §10):** недельный дайджест, фильтр периода и экспорт PNG/PDF,
голосовые (STT), напоминания о целях с дедлайнами, кнопки/инлайн-клавиатуры, шифрование БД.

**Жёсткие запреты:** внешние Python-пакеты (`pip`), npm, CDN и внешние шрифты/картинки
в дашборде, запись в живую Obsidian-базу из тестов, секреты в логах и в git.

## 6. Принципы и стандарты

1. **Только stdlib.** Python 3.9+ (на Mac `/usr/bin/python3` = 3.9.6, `/usr/local/bin/python3`
   = 3.13.14; установщик предпочитает второй, `install.sh:162`).
2. **Offline-first.** Сеть нужна только Telegram и (опционально) LLM. Дашборд работает
   двойным кликом без интернета.
3. **LLM опционален.** Любой сбой LLM → скриптованные вопросы и эвристика разбора;
   данные пишутся всегда (`src/parsing.py`, `src/llm.py`).
4. **Текст пользователя неприкосновенен.** Daily-заметка только дописывается; цели
   перегенерируются только между маркерами `<!-- lifeos:goals:start/end -->`.
5. **Идемпотентность.** Каждая запись — маркер `<!-- lifeos:entry:ID -->`; повтор не дублирует.
6. **Ошибка не роняет цикл.** Любое исключение ловится, логируется, процесс живёт
   (ТЗ §7); запись остаётся в БД с `written=0` и допишется при следующем запуске.
7. **Секреты локально.** `config.json` — права 600; токен и ключ не печатаются в логи
   и не попадают в `repr` (`tests/test_telegram.py::test_repr_hides_token`).
8. **Русский интерфейс.** Все тексты бота, README и отчётов — по-русски, «ты», без морали.
9. **Один процесс.** launchd + pid-лок `data/lifeos.pid` (`src/main.py:66`), защита от 409.
10. **Тесты — доказательство.** Готовность = код + прогон + отчёт; цифры прогонов
    фиксируются в `TEST_HISTORY.md`, а не в переписке.

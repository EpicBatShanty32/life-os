# Спека v5: автономный агент в Telegram (адаптированная)

Это рабочая версия спеки. Исходная была больше и обещала то, чего нет в
распоряжении: распознавание фото, чеков и скриншотов. **Фото и vision убраны**
(«похуй») — вместо них текст, голос и пересылки. Всё остальное сведено к тому,
что реально сделать на этой машине: SQLite, один воркер, один бот.

Главное отличие от скриптового бота: модель **думает и вызывает инструменты**.
Она сама решает, что прочитать, что записать и что ответить, а не подбирает
регулярное выражение под фразу.

---

## 1. Что уже работает (этап 1, сделан)

`app/bot/agent.py` — цикл ReAct поверх той же базы, что и сайт:

- **15 инструментов**: создать дело, закрыть дело, расход, доход, запись в
  дневник, заметка, привычка, чек-ин энергии, сводка дня, сводка недели,
  деньги за период, поиск по базе, отмена последнего, запомнить факт,
  отложенная мысль.
- **Одна фраза → несколько записей.** «Потратила 2400 на продукты, завтра в 12
  бухгалтеру, идея про выгорание» даёт расход, дело со временем и заметку.
- **Журнал** (`agent_journal`): что сделано, с какими аргументами и как откатить.
- **Откат**: `/undo` или «отмени последнее» — удаляет последнее действие агента
  по журналу, а если журнал пуст — прежнюю «последнюю запись».
- **Память**: `agent_messages` (последние 10 реплик в контексте),
  `agent_memory` (досье: стиль, привычки, просьбы), `agent_thoughts`
  (отложенные мысли с временем срабатывания).
- **Запасной путь**: нет ключа / упала сеть / модель молчит — фраза уходит в
  прежний разбор правилами. Человек видит ответ, а не ошибку.
- **Тон**: в промпте запрещены штампы («задача успешно добавлена»), задан
  один уточняющий вопрос вместо анкеты, режим «устал — сначала состояние».

Схема БД: v5 (четыре аддитивные таблицы). Существующие данные не меняются.

Проверка без сети: `python3 -m pytest app/tests/test_agent.py -q` — 14 тестов
на фейковой модели. Живая проверка — прогон фраз через реальную модель.

## 2. Что дальше (по порядку, каждый этап самостоятелен)

### Этап 2. Голос
Расшифровка на этой машине (`faster-whisper`), движок `transcribe.engine`
уже есть в настройках. Голос идёт тем же путём, что текст: `handle_transcript`
→ `_understand` → агент. Ничего в агенте менять не надо.

### Этап 3. Инициатива (сердцебиение)
Цикл в существующем воркере раз в 1–2 часа:

1. собрать слепок (как `agent.snapshot`), плюс `due_thoughts`;
2. спросить модель: «есть ли повод написать? если нет — ответь SILENT»;
3. если повод есть — отправить одно сообщение, отметить мысль отправленной.

Жёсткие правила, без которых это вредно:
- не больше **2** инициативных сообщений в сутки;
- тихие часы из настроек (`app.quiet_hours`);
- протокол тишины: нет ответа на инициативу — не пинговать до следующего окна;
- `/pause` и «не пиши первым» — стоп проактивности, приём записей остаётся;
- журнал решений: почему написал и почему промолчал (иначе не отладить).

### Этап 4. Досье и смысловой поиск
Сейчас досье пополняется, когда модель сама зовёт `remember`. Дальше:
- после значимого диалога — отдельный дешёвый вызов «что тут стоит запомнить»;
- смысловой поиск: `sqlite-vec` + эмбеддинги вместо LIKE в `search`.
  Векторная БД отдельным сервисом (Qdrant) не нужна.

### Этап 5. Вечерний дебрифинг и отчёты
- вечером: разобрать незакрытые дела, собрать запись в дневник, закрыть день;
- неделя/месяц: аналитика по всем разделам + фокус на следующую неделю.

## 3. Решения (и почему так)

| Вопрос | Решение | Почему |
| :--- | :--- | :--- |
| Хранилище | SQLite, те же таблицы | Один файл, бэкап уже есть |
| Векторы | `sqlite-vec`, позже | Не тащить второй сервис |
| Очередь | существующий воркер | Celery не нужен |
| Фото/чеки | **не делаем** | Нужна vision-модель, отдельные деньги |
| Модель | `deepseek-v4.1-flash-1017` через `api.samp.team` | Уже настроена, tool calling работает |
| Стоимость | дешёвая модель на рутину, дорогая на разговор | Каждое сообщение — 1–3 вызова |

## 4. Ограничения, которые надо помнить

- **Модель иногда ошибается.** Поэтому журнал и `/undo` — часть ядра, а не
  «когда-нибудь потом».
- **Приватность.** Текст дневника уходит в облачную модель. Решить осознанно.
- **Скорость.** Ответ 5–15 секунд — норма для этого стека.
- **Слепок дня в промпте.** Он растёт; держать его коротким (сейчас ≤900 знаков).

## 5. Как проверить, что живо

```bash
cd life-os
python3 -m pytest app/tests/test_agent.py -q   # ядро без сети
tail -f data/logs/bot.log                      # «агент включён: 15 инструментов»
```

В Telegram: любая свободная фраза → ответ агента; `/undo` → откат.
Если в логе «агент выключен (нет ключа LLM)» — работает старый разбор.

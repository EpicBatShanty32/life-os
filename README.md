# Life OS — личный Telegram-агент + Obsidian + дашборд

**Версия 0.1.2 · 17 ноября 2026** · [Что нового](CHANGELOG.md) · [Релиз](RELEASE_NOTES.md)

Бот в Telegram, который несколько раз в день сам пишет тебе, подробно расспрашивает
о делах, еде, тренировках, целях и настроении, складывает ответы в твою базу Obsidian
и собирает наглядный дашборд.

Всё работает на твоём Mac: база Obsidian, история ответов и дашборд лежат только у тебя.
Наружу уходят только сообщения в Telegram. Если включён «умный» режим (LLM) и в конфиге
есть ключ `llm.api_key`, то для уточнений на сервер `api.samp.team` отправляются твои
ответы и последние сообщения диалога. Выключи `llm.enabled` — и все данные останутся
на Mac: вопросы будут задаваться по заранее заготовленному скрипту.

## Для агентов и людей, которые читают впервые

**Life OS 0.1.2** — локальный Telegram-бот: сам задаёт вопросы о дне, еде, тренировках
и целях, пишет ответы в Obsidian и собирает офлайн-дашборд на Mac. Публичного сайта
и облака нет: наружу уходят только Telegram и (если включён) LLM.

- Проверить без токена и интернета: `bash check.sh`; запуск без записи: `python3 src/main.py --dry-run --once`.
- Чего нет в 0.1.2: недельного дайджеста (выключен), голосовых, кнопок, экспорта PNG/PDF, шифрования БД; одна учётка.
- Машинная карта: [`llms.txt`](llms.txt). Границы, стандарты и приёмка: [`studio/PROJECT_BIBLE.md`](studio/PROJECT_BIBLE.md).

## Приватность и «умный» режим (LLM)

- **Всё основное — на Mac.** Дневник пишется в твою базу Obsidian, история ответов и
  дашборд тоже лежат локально.
- **Наружу уходит только Telegram.** Сообщения идут через серверы Telegram — как любая
  переписка в этом мессенджере.
- **«Умный» режим — по желанию.** Если `llm.enabled` включён и заполнен `llm.api_key`,
  бот просит модель сформулировать уточняющий вопрос или ответить на свободный текст.
  В запрос попадают твой ответ, вопрос бота и последние сообщения диалога; уходит это
  на `llm.base_url` (по умолчанию `https://api.samp.team/v1`).
- **Как выключить.** Поставь `"llm.enabled": false` в `config.json` — или просто не
  заполняй `llm.api_key`. Бот будет задавать заранее заготовленные вопросы, и данные
  останутся на Mac.
- **Ограничения.** Ответ модели обрезается до 4000 символов; ждать дольше 30 секунд бот
  не будет; после 3 ошибок подряд «умные» вызовы выключаются на 10 минут — бот
  продолжает работать по скрипту и потом сам пробует снова. Данные при этом
  не теряются.
- **Чего бот не делает.** Не отправляет файлы из Obsidian, не пишет за пределы папки
  из `obsidian.vault_path` и не обращается в интернет никуда, кроме Telegram и
  (если включён) `llm.base_url`.

## Шаг 1. Создай бота в Telegram

1. Открой Telegram и в поиске набери **@BotFather** (у него галочка «verified»).
2. Нажми **Start**, затем отправь сообщение: `/newbot`
3. BotFather спросит имя бота — напиши, как он будет называться в чате, например `Life OS`.
4. Затем спросит username — латиницей, обязательно с окончанием `bot`,
   например `my_lifeos_bot`.
5. BotFather пришлёт сообщение, в котором будет строка вида:

   ```
   Use this token to access the HTTP API:
   1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

6. **Скопируй этот токен.** Это пароль бота: не пересылай его никому
   и не выкладывай в интернет.

Если токен потерялся: снова напиши @BotFather → `/mybots` → выбери бота → **API Token**.

---

## Шаг 2. Узнай свой chat_id

1. В Telegram найди **@userinfobot**, нажми **Start**.
2. Он ответит сообщением, где будет:

   ```
   Id: 123456789
   ```

3. Это число и есть твой chat_id (не username!).

Если этот бот не отвечает — попробуй **@getmyid_bot**: он тоже покажет твой Id.

## Шаг 3. Впиши токен и chat_id в конфиг

**Если программа ещё не установлена** — создай конфиг в папке проекта:

```
cd "/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent"
cp config/config.example.json config/config.json
chmod 600 config/config.json
open -e config/config.json
```

`chmod 600` делает файл доступным только тебе — в нём лежит токен бота.

**Если программа уже установлена** — правь установленный конфиг:

```
open -e "$HOME/Library/Application Support/LifeOS/config.json"
```

В открывшемся файле найди в самом начале блок `"telegram"` и замени значения:

```
  "telegram": {
    "token": "1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "allowed_chat_id": 123456789,
    "api_base": "https://api.telegram.org"
  },
```

- `token` — вставь токен из шага 1 (в кавычках).
- `allowed_chat_id` — число из шага 2 (без кавычек).
- Остальное в этом блоке не меняй.

Теперь найди блок `"obsidian"` и поправь `vault_path`:

```
  "obsidian": {
    "enabled": true,
    "vault_path": "/Users/you/Documents/Obsidian/Мой vault",
    …остальные ключи…
  },
```

- `vault_path` — путь к твоей базе Obsidian. Замени плейсхолдер на настоящий путь
  (например, `/Users/user/Documents/Мой vault`). Если оставить плейсхолдер, бот
  установится и будет работать, но запись в Obsidian отключится — записи останутся
  только в базе и на дашборде.

> Агент пишет только внутри папки из `obsidian.vault_path`. Если путь выходит за её
> пределы (`../`, симлинк наружу), запись отклоняется — файлы вне базы не тронуты.

Сохрани файл: **Cmd+S**. Закрой TextEdit.

Проверь права (в выводе должно быть `-rw-------` — файл видишь только ты):

```
ls -l config/config.json
```

Если стоит `-rw-r--r--` — повтори `chmod 600 config/config.json`.

> Токен хранится в обычном текстовом файле, но с правами «только для тебя»
> (600). Не отправляй этот файл в чаты и не выкладывай в интернет.

## Шаг 4. Установи программу

В Терминале (Программы → Утилиты → Терминал):

```
cd "/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent"
bash install.sh
```

Что сделает установщик:

1. Скопирует программу в `~/Library/Application Support/LifeOS`
   (так macOS разрешает автозапуск).
2. Создаст `config.json` (правки из проекта сохранятся; существующий конфиг
   в папке установки **не перезаписывается**).
3. Если в `~/.dsh/.credentials.yaml` есть ключ `DDD_API_KEY` — подставит его в конфиг
   автоматически (ключ нигде не печатается). Без ключа бот тоже работает:
   задаёт заранее заготовленные вопросы вместо «умных» уточнений.
4. Поставит автозапуск `com.lifeos.agent` — бот стартует при входе в систему
   и сам перезапускается, если упадёт.
5. Запустит бота и напечатает статус.

Если появилось сообщение «Пока не запускаю: в config.json не заполнено…» —
значит установщик не увидел токен/chat_id: вернись к шагу 3 и примени изменения.

## Шаг 5. Проверь, что всё работает

В Терминале:

```
launchctl list | grep lifeos
```

Должна появиться строка `com.lifeos.agent` (с числом PID — значит процесс жив).

Лог (последние строки):

```
tail -n 20 "$HOME/Library/Logs/LifeOS/agent.log"
```

Проверка в Telegram: напиши боту `/start` — он поздоровается. Команда `/status`
покажет состояние: пауза, слоты дня, активная сессия, записи и цели.

Проверить сам проект (работает без токена, Telegram и интернета):

```
cd "<папка проекта>"
bash check.sh
```

Должно закончиться строкой `PASS …`. Если `FAIL` — в выводе будет, что именно сломалось.

По расписанию (время московское) бот сам напишет:

| Время | Слот | О чём спрашивает |
|---|---|---|
| 08:30 | утро | что главное сегодня, 2–3 задачи к этому, одна главная цель |
| 14:00 | день | что ел, сколько воды, энергия и фокус (от 1 до 5) |
| 21:30 | вечер | тренировка, итоги задач, еда за день, настроение и энергия, что запомнить |
| вс 21:00 | неделя | итоги недели, тело, цели, планы (по умолчанию выключено) |

Отвечать можно сразу на несколько пунктов — «ел пасту, воды литр, задачи закрыл»:
бот разберёт сообщение и сохранит всё.

### Первый запуск: знакомство

Пока знакомство не пройдено, бот не задаёт плановых вопросов — сначала `/start`.

1. Бот поздоровается и спросит: начать сейчас или подождать.
2. Ответь «да» — первый разговор начнётся сразу (утро, день или вечер — зависит
   от времени). Ответь «вечером» — бот подождёт ближайшего слота; это не обязательно
   вечер, следующим слотом может оказаться утро.
3. Дальше бот спрашивает сам по расписанию.

Знакомство включается флагом `app.onboarding` — в установленном конфиге он включён.
Проходится один раз; потом `/start` просто показывает приветствие.

### Тихие часы

В установленном конфиге тихие часы стоят с 23:00 до 08:00: в это время бот сам
не пишет, плановые вопросы не приходят. Написать ему можно — ответит и сохранит.
Настраивается в `app.quiet_hours`, пустой список `[]` — без тихих часов.

## Шаг 6. Открой дашборд

```
open "$HOME/Library/Application Support/LifeOS/dashboard/index.html"
```

Дашборд — обычная страница в браузере: цели с прогресс-барами, сон, тренировки,
питание и вода, настроение/энергия, привычки, журнал и «карта» отметок за 8 недель.
Слева — меню: логотип, все разделы, поиск по журналу, серия дней и переключатель
темы. Меню сворачивается до иконок (кнопка над списком) и запоминает состояние;
на телефоне оно прячется за кнопкой в шапке. Тема тоже запоминается.

- Поиск в меню фильтрует журнал по тексту и категории, показывает «найдено N»
  и очищается по Esc. Быстрый переход к поиску — Cmd/Ctrl+K или «/».
- Перейти к разделу можно с клавиатуры: Tab по меню, Enter. Активный раздел
  подсвечивается и в адресе страницы остаётся его якорь (`#sec-sleep`).

- Файл появляется после первого сохранения записи. Если дашборда ещё нет —
  напиши боту `/дизайн` и открой снова.
- Данные обновляются при каждой новой записи; обновить страницу вручную —
  кнопка «Обновить» или F5.
- Привычки тоже видны на дашборде: отметь привычку командой `/habit зарядка` —
  в карточке «Привычки» появится строка с серией (сколько дней подряд идут)
  и отметками за последнюю неделю. Список всех привычек и серий — `/habits`.

## Шаг 7. Команды бота

| Команда | Что делает |
|---|---|
| `/start` или `старт` | приветствие, знакомство, вернуться к боту |
| `/status` или `статус` | состояние: пауза, слоты, сессия, записи и цели |
| `/today` или `сегодня` | записи за сегодня: текст, время, итоги дня |
| `/report` или `отчёт` | сводка за 7 дней |
| `/goals` или `цели` | список целей и прогресс |
| `/add_goal` | добавить цель (формат — ниже) |
| `/habit <название>` или `привычка` | отметить привычку за сегодня: `/habit зарядка` |
| `/habits` или `привычки` | привычки и серии: сколько дней подряд |
| `/pause` или `пауза` | поставить плановые вопросы на паузу |
| `/resume` или `продолжить` | снять с паузы |
| `/skip` или `пропустить` | пропустить текущий вопрос |
| `/stop` или `стоп` | прервать текущий разговор |
| `/help` или `помощь` | эта справка по командам |
| `/дизайн` или `дашборд` | перерисовать дашборд |

Команды понимаются и без слэша по-русски: «сегодня», «статус», «пауза» и т.д.
`/today` показывает сами записи (примерно 120 символов текста, по границе слова)
и итоги дня: воду, сон, настроение.

Цель добавляется одной строкой:

```
/add_goal Пробежать 10 км | 3/10 | 2027-06-01
```

`|` — разделитель; прогресс (`3/10`) и срок можно не указывать.

**Откуда берутся проценты.** Первое число — это точка старта: бот запоминает
её в момент создания цели. Прогресс считается не «сколько сделано от нуля»,
а «сколько пройдено от старта до цели», поэтому новая цель сразу показывает
0%, а не «уже 30%».

Пример: сейчас 92 кг, цель — 78.

```
/add_goal Похудеть до 78 | 92/78
```

| Что стоит в цели | Прогресс |
|---|---|
| 92 (в день создания) | 0% |
| 85 | 50% |
| 78 | 100% |

Направление бот определяет сам: у целей про вес («похудеть», «сбросить»)
лучше меньшее значение, у остальных — большее. Поэтому «читать 12 книг»
растёт вверх, а «похудеть до 78» — вниз.

Проценты совпадают везде: в `/goals`, в таблице `Проекты/Life OS/Цели.md`
в Obsidian и в полосе цели на дашборде — формула одна и та же.

Значение цели хранится в ней самой и задаётся при создании. Отдельной команды
«обновить прогресс» в этой версии нет: если добавить цель с тем же названием
ещё раз, появится вторая цель (снова с 0%), а старая не обновится.

Можно не ждать расписания и просто **написать боту свободным текстом** — он
по-человечески ответит, вытащит из сообщения данные (еду, воду, тренировку,
настроение и т.п.) и сохранит их в Obsidian. Без «умного» режима приветствия
и «спасибо» в дневник не записываются — бот просто отвечает.

Куда попадают записи:

- дневная заметка: `01 Daily/YYYY-MM-DD.md` (дописывается в конец, разделы
  `## Еда (агент)`, `## Тренировка (агент)`, `## Задачи (агент)` и т.д.);
- цели: `Проекты/Life OS/Цели.md` (таблица обновляется автоматически);
- машинная копия данных: `Life OS/data/entries.jsonl` и `goals.json`.

## Шаг 8. Изменить время, отключить или удалить

**Время и слоты** правятся в конфиге
`~/Library/Application Support/LifeOS/config.json`:

```
  "schedule": {
    "morning": { "time": "08:30", "enabled": true },
    "midday":  { "time": "14:00", "enabled": true },
    "evening": { "time": "21:30", "enabled": true },
    "weekly":  { "time": "21:00", "weekday": 6, "enabled": false }
  },
```

- время — в 24-часовом формате `"ЧЧ:ММ"`;
- чтобы отключить слот — `"enabled": false`;
- недельный слот: `"enabled": true` и `"weekday": 6` (воскресенье).

**Знакомство и тихие часы** — в блоке `"app"` того же файла:

```
  "app": {
    "onboarding": true,
    "quiet_hours": ["23:00", "08:00"]
  },
```

- `onboarding` — `true`: при первом запуске бот сначала знакомится; `false`: сразу
  спрашивает по расписанию;
- `quiet_hours` — промежуток, в который бот сам не пишет; `[]` — тихих часов нет.
  Если начало больше конца (как `23:00` → `08:00`), это ночь через полночь.
- если блока `"app"` нет вовсе — знакомство и тихие часы выключены.

После правки применить:

```
cd "/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent"
bash install.sh --reload
```

(то же можно запускать из `~/Library/Application Support/LifeOS`, если папки
проекта под рукой нет).

**Снять с автозапуска, данные сохранить:**

```
cd "/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent"
bash uninstall.sh
```

**Удалить всё** (конфиг с токеном, база, логи):

```
bash uninstall.sh --purge
```

## Шаг 9. Если что-то не так

Сначала всегда смотри лог:

```
tail -n 50 "$HOME/Library/Logs/LifeOS/agent.log"
```

**Бот молчит, не отвечает на /start:**
- `launchctl list | grep lifeos` — если строки нет, запусти `bash install.sh --reload`;
- проверь, что в `config.json` заполнены `token` и `allowed_chat_id`;
- проверь паузу: `/status`; если пауза — `/resume`;
- бот не пишет вне расписания — это нормально, он ждёт слота; напиши `/start`;
- если это первый запуск — сначала пройди знакомство: ответь на `/start` «да» или
  «вечером»;
- с 23:00 до 08:00 бот сам не пишет — это тихие часы, не поломка.

**В логе `401 Unauthorized` или «Unauthorized»:**
токен неверный или отозван. @BotFather → `/mybots` → твой бот → **API Token**
(или `/revoke`, чтобы выпустить новый). Вставь новый токен в `config.json`,
затем `bash install.sh --reload`.

**В логе `409 Conflict`:**
запущено два бота одновременно. Не запускай `python3 src/main.py` вручную, если
уже стоит автозапуск. Проверь `ps aux | grep "src/main.py"`, лишний процесс
останови (`kill <PID>`), затем `bash install.sh --reload`.

**В логе «Operation not permitted» при записи в Obsidian:**
macOS не пускает программу в папку Documents. Открой
**Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску**,
нажми **+**, затем **Cmd+Shift+G** и вставь путь к Python, которым запускается бот
(установщик печатает его в строке «интерпретатор», обычно
`/usr/local/bin/python3`). Включи переключатель и выполни `bash install.sh --reload`.

**Ошибки «карантин» macOS** (файлы скачаны/скопированы из интернета, launchd
не может их прочитать): в Терминале

```
xattr -dr com.apple.quarantine "$HOME/Library/Application Support/LifeOS"
bash install.sh --reload
```

Установщик обычно снимает карантин сам.

**Ошибки сети, таймауты, `api.telegram.org` недоступен:**
боту нужен доступ к Telegram. Если включён VPN (например, INCY), проверь, что он
не блокирует Telegram. Агент запускается через launchd и не наследует настройки
прокси из терминала. Проверить доступ:
`curl -s -o /dev/null -w '%{http_code}\n' https://api.telegram.org`
(должен вернуться HTTP-код, а не таймаут).

**LLM-уточнения не работают** (в логе `llm: error`/`401`):
бот продолжит работать в скриптованном режиме, все данные сохранятся.
Ключ можно вписать вручную в `config.json` → `llm.api_key`, затем `--reload`.
Ключ также подхватывается из `~/.dsh/.credentials.yaml` при установке.
Если в логе «LLM: 3 ошибок подряд — выключаю „умные“ вызовы», это защита от
зависшего сервера: через 10 минут бот попробует снова сам.

**Дашборд пустой или не открывается:**
файл `dashboard/index.html` появляется после первой записи. Напиши боту `/дизайн`,
потом открой снова. Пустые карточки — это нормально, пока нет данных.

**Изменил `config.json`, но ничего не поменялось:**
конфиг читается при старте. Примени изменения: `bash install.sh --reload`.

**Лог стал большим:**
при каждом `install.sh`/`--reload` файл больше 5 МБ уходит в `agent.log.1`
(агент хранит один бэкап), а `agent.log` начинается заново. Служебный вывод
launchd лежит отдельно — `agent.out.log`; его крутит команда
`python3 tools/health.py --rotate` (только при остановленном боте).

**Проверить программу вручную** (без Telegram):

```
cd "$HOME/Library/Application Support/LifeOS"
python3 src/main.py --dry-run --once
```

`--dry-run` ничего не сохраняет: не трогает рабочую базу, Obsidian и расписание —
это безопасная проверка «а вообще запускается ли». Слот дня он не «съедает».

## Life OS v3 (`app/`) — новое ядро

Рядом со старым контуром живёт переписанное приложение: FastAPI-сервер,
React-SPA и Telegram-бот на aiogram. Оно не мешает установленной версии и
запускается отдельно.

- Подробности запуска — [`app/README.md`](app/README.md).
- Демо-данные: `python3 -m app.server.seeder --db data/lifeos-v3.db --days 120`.
- Сервер: `python3 -m uvicorn app.server.main:app --port 8787`, SPA — на `/`.
- Тесты ядра: `python3 -m pytest app/tests -q` (225 штук).

## Где что лежит

| Что | Где |
|---|---|
| Программа, конфиг, база | `~/Library/Application Support/LifeOS` |
| Конфиг (токен, chat_id, расписание, тихие часы) | `~/Library/Application Support/LifeOS/config.json` |
| База данных | `~/Library/Application Support/LifeOS/data/lifeos.db` |
| Логи | `~/Library/Logs/LifeOS/agent.log` (служебный вывод launchd — `agent.out.log`) |
| Дашборд | `~/Library/Application Support/LifeOS/dashboard/index.html` |
| Автозапуск | `~/Library/LaunchAgents/com.lifeos.agent.plist` |
| Версия и история | `VERSION`, `CHANGELOG.md`, `RELEASE_NOTES.md` в папке проекта |
| Проверка целостности | `bash check.sh` в папке проекта |
| Папка проекта (установщик) | `/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent` |

Если папка проекта переехала, в командах подставляй её новый путь.

Важно: `config.json` с токеном — личный файл, не выкладывай его в git и не
пересылай. Права 600 выставлены установщиком автоматически.

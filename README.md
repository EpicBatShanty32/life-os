# Life OS — личный Telegram-агент + Obsidian + дашборд

**Версия 0.1.0 · 16 ноября 2026** · [Что нового](CHANGELOG.md) · [Релиз](RELEASE_NOTES.md)

Бот в Telegram, который несколько раз в день сам пишет тебе, подробно расспрашивает
о делах, еде, тренировках, целях и настроении, складывает ответы в твою базу Obsidian
и собирает наглядный дашборд.

Всё работает на твоём Mac: база Obsidian, история ответов и дашборд лежат только у тебя.
Интернет нужен для Telegram и — если включён «умный» режим (LLM) — для уточняющих
вопросов: в этом случае текст ответов и часть истории уходит на api.samp.team.
Можно работать полностью локально: выключи `llm.enabled` в конфиге — тогда агент
задаёт вопросы по скрипту, а данные никуда не уходят.

---

## Что понадобится

- Mac с macOS: Python 3.9+ уже есть в системе, установщик выберет подходящий.
- Telegram-аккаунт.
- 10–15 минут.

## Шаг 1. Создай бота в Telegram

1. Открой Telegram и в поиске набери **@BotFather** (у него галочка «verified»).
2. Нажми **Start**, затем отправь сообщение: `/newbot`
3. BotFather спросит имя бота — напиши, как он будет называться в чате, например `Life OS`.
4. Затем спросит username — латиницей, обязательно с окончанием `bot`,
   например `my_lifeos_bot`.
5. BotFather пришлёт сообщение, в котором будет строка вида:

   ```
   Use this token to access the HTTP API:
   1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ```

6. **Скопируй этот токен.** Это пароль бота: не пересылай его никому
   и не выкладывай в интернет.

Если токен потерялся: снова напиши @BotFather → `/mybots` → выбери бота → **API Token**.

---

## Шаг 2. Узнай свой chat_id

1. В Telegram найди **@userinfobot**, нажми **Start**.
2. Он ответит сообщением, где будет:

   ```
   Id: 123456789
   ```

3. Это число и есть твой chat_id (не username!).

Если этот бот не отвечает — попробуй **@getmyid_bot**: он тоже покажет твой Id.

---

## Шаг 3. Впиши токен и chat_id в конфиг

**Если программа ещё не установлена** — создай конфиг в папке проекта:

```
cd "/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent"
cp config/config.example.json config/config.json
open -e config/config.json
```

**Если программа уже установлена** — правь установленный конфиг:

```
open -e "$HOME/Library/Application Support/LifeOS/config.json"
```

В открывшемся файле найди в самом начале блок `"telegram"` и замени значения:

```
  "telegram": {
    "token": "1234567890:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx",
    "allowed_chat_id": 123456789,
    "api_base": "https://api.telegram.org"
  },
```

- `token` — вставь токен из шага 1 (в кавычках).
- `allowed_chat_id` — число из шага 2 (без кавычек).
- Остальное в этом блоке не меняй.

Сохрани файл: **Cmd+S**. Закрой TextEdit.

> Токен хранится в обычном текстовом файле, но с правами «только для тебя»
> (600). Не отправляй этот файл в чаты и не выкладывай в интернет.

## Шаг 4. Установи программу

В Терминале (Программы → Утилиты → Терминал):

```
cd "/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent"
bash install.sh
```

Что сделает установщик:

1. Скопирует программу в `~/Library/Application Support/LifeOS`
   (так macOS разрешает автозапуск).
2. Создаст `config.json` (правки из проекта сохранятся; существующий конфиг
   в папке установки **не перезаписывается**).
3. Если в `~/.dsh/.credentials.yaml` есть ключ `DDD_API_KEY` — подставит его в конфиг
   автоматически (ключ нигде не печатается). Без ключа бот тоже работает:
   задаёт заранее заготовленные вопросы вместо «умных» уточнений.
4. Поставит автозапуск `com.lifeos.agent` — бот стартует при входе в систему
   и сам перезапускается, если упадёт.
5. Запустит бота и напечатает статус.

Если появилось сообщение «Пока не запускаю: в config.json не заполнено…» —
значит установщик не увидел токен/chat_id: вернись к шагу 3 и примени изменения.

## Шаг 5. Проверь, что всё работает

В Терминале:

```
launchctl list | grep lifeos
```

Должна появиться строка `com.lifeos.agent` (с числом PID — значит процесс жив).

Лог (последние строки):

```
tail -n 20 "$HOME/Library/Logs/LifeOS/agent.log"
```

Проверка в Telegram: напиши боту `/start` — он ответит приветствием.
Команда `/status` покажет, включён ли бот и когда следующее сообщение.

Проверить сам проект (работает без токена, Telegram и интернета):

```
cd "<папка проекта>"
bash check.sh
```

Должно закончиться строкой `PASS …`. Если `FAIL` — в выводе будет, что именно сломалось.

По расписанию (время московское) бот сам напишет:

| Время | Слот | О чём спрашивает |
|---|---|---|
| 08:30 | утро | план на день, 3 главные задачи, цели |
| 14:00 | день | что ел, сколько воды, как энергия |
| 21:30 | вечер | тренировка, итоги задач, еда за день, настроение, мысли |
| вс 21:00 | неделя | итоги недели (по умолчанию выключено) |

## Шаг 6. Открой дашборд

```
open "$HOME/Library/Application Support/LifeOS/dashboard/index.html"
```

Дашборд — обычная страница в браузере: цели с прогресс-барами, сон, тренировки,
питание и вода, настроение/энергия, привычки, журнал и «карта» отметок за 8 недель.

- Файл появляется после первого сохранения записи. Если дашборда ещё нет —
  напиши боту `/дизайн` и открой снова.
- Данные обновляются при каждой новой записи; обновить страницу вручную —
  кнопка «Обновить» или F5.

## Шаг 7. Команды бота

| Команда | Что делает |
|---|---|
| `/start` или `старт` | начать разговор / вернуться к боту |
| `/status` или `статус` | состояние: пауза, следующее сообщение |
| `/today` или `сегодня` | что уже записано за сегодня |
| `/report` или `отчёт` | сводка за неделю |
| `/goals` или `цели` | список целей |
| `/add_goal` | добавить цель (бот спросит детали) |
| `/pause` или `пауза` | поставить опросы на паузу |
| `/resume` или `продолжить` | снять с паузы |
| `/skip` или `пропустить` | пропустить текущий вопрос |
| `/help` или `помощь` | помощь по командам |
| `/дизайн` | перерисовать дашборд |

Можно не ждать расписания и просто **написать боту свободным текстом** — он
по-человечески ответит, вытащит из сообщения данные (еду, воду, тренировку,
настроение и т.п.) и сохранит их в Obsidian.

Куда попадают записи:

- дневная заметка: `01 Daily/YYYY-MM-DD.md` (дописывается в конец, разделы
  `## Еда (агент)`, `## Тренировка (агент)`, `## Задачи (агент)` и т.д.);
- цели: `Проекты/Life OS/Цели.md` (таблица обновляется автоматически);
- машинная копия данных: `Life OS/data/entries.jsonl` и `goals.json`.

## Шаг 8. Изменить время, отключить или удалить

**Время и слоты** правятся в конфиге
`~/Library/Application Support/LifeOS/config.json`:

```
  "schedule": {
    "morning": { "time": "08:30", "enabled": true },
    "midday":  { "time": "14:00", "enabled": true },
    "evening": { "time": "21:30", "enabled": true },
    "weekly":  { "time": "21:00", "weekday": 6, "enabled": false }
  },
```

- время — в 24-часовом формате `"ЧЧ:ММ"`;
- чтобы отключить слот — `"enabled": false`;
- недельный слот: `"enabled": true` и `"weekday": 6` (воскресенье).

После правки применить:

```
cd "/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent"
bash install.sh --reload
```

(то же можно запускать из `~/Library/Application Support/LifeOS`, если папки
проекта под рукой нет).

**Снять с автозапуска, данные сохранить:**

```
cd "/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent"
bash uninstall.sh
```

**Удалить всё** (конфиг с токеном, база, логи):

```
bash uninstall.sh --purge
```

## Шаг 9. Если что-то не так

Сначала всегда смотри лог:

```
tail -n 50 "$HOME/Library/Logs/LifeOS/agent.log"
```

**Бот молчит, не отвечает на /start:**
- `launchctl list | grep lifeos` — если строки нет, запусти `bash install.sh --reload`;
- проверь, что в `config.json` заполнены `token` и `allowed_chat_id`;
- проверь паузу: `/status`; если пауза — `/resume`;
- бот не пишет вне расписания — это нормально, он ждёт слота; напиши `/start`.

**В логе `401 Unauthorized` или «Unauthorized»:**
токен неверный или отозван. @BotFather → `/mybots` → твой бот → **API Token**
(или `/revoke`, чтобы выпустить новый). Вставь новый токен в `config.json`,
затем `bash install.sh --reload`.

**В логе `409 Conflict`:**
запущено два бота одновременно. Не запускай `python3 src/main.py` вручную, если
уже стоит автозапуск. Проверь `ps aux | grep "src/main.py"`, лишний процесс
останови (`kill <PID>`), затем `bash install.sh --reload`.

**В логе «Operation not permitted» при записи в Obsidian:**
macOS не пускает программу в папку Documents. Открой
**Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску**,
нажми **+**, затем **Cmd+Shift+G** и вставь путь к Python, которым запускается бот
(установщик печатает его в строке «интерпретатор», обычно
`/usr/local/bin/python3`). Включи переключатель и выполни `bash install.sh --reload`.

**Ошибки «карантин» macOS** (файлы скачаны/скопированы из интернета, launchd
не может их прочитать): в Терминале

```
xattr -dr com.apple.quarantine "$HOME/Library/Application Support/LifeOS"
bash install.sh --reload
```

Установщик обычно снимает карантин сам.

**Ошибки сети, таймауты, `api.telegram.org` недоступен:**
боту нужен доступ к Telegram. Если включён VPN (например, INCY), проверь, что он
не блокирует Telegram. Агент запускается через launchd и не наследует настройки
прокси из терминала. Проверить доступ:
`curl -s -o /dev/null -w '%{http_code}\n' https://api.telegram.org`
(должен вернуться HTTP-код, а не таймаут).

**LLM-уточнения не работают** (в логе `llm: error`/`401`):
бот продолжит работать в скриптованном режиме, все данные сохранятся.
Ключ можно вписать вручную в `config.json` → `llm.api_key`, затем `--reload`.
Ключ также подхватывается из `~/.dsh/.credentials.yaml` при установке.

**Дашборд пустой или не открывается:**
файл `dashboard/index.html` появляется после первой записи. Напиши боту `/дизайн`,
потом открой снова. Пустые карточки — это нормально, пока нет данных.

**Изменил `config.json`, но ничего не поменялось:**
конфиг читается при старте. Примени изменения: `bash install.sh --reload`.

**Лог стал большим:**
при каждом `install.sh`/`--reload` файл больше 5 МБ уходит в `agent.log.1`
(агент хранит до трёх бэкапов: `agent.log.1`…`agent.log.3`), а `agent.log`
начинается заново. Служебный вывод launchd лежит отдельно — `agent.out.log`.

**Проверить программу вручную** (без Telegram):

```
cd "$HOME/Library/Application Support/LifeOS"
python3 src/main.py --dry-run --once
```

`--dry-run` ничего не сохраняет: не трогает рабочую базу, Obsidian и расписание —
это безопасная проверка «а вообще запускается ли». Слот дня он не «съедает».

## Где что лежит

| Что | Где |
|---|---|
| Программа, конфиг, база | `~/Library/Application Support/LifeOS` |
| Конфиг (токен, chat_id, расписание) | `~/Library/Application Support/LifeOS/config.json` |
| База данных | `~/Library/Application Support/LifeOS/data/lifeos.db` |
| Логи | `~/Library/Logs/LifeOS/agent.log` (служебный вывод launchd — `agent.out.log`) |
| Дашборд | `~/Library/Application Support/LifeOS/dashboard/index.html` |
| Автозапуск | `~/Library/LaunchAgents/com.lifeos.agent.plist` |
| Версия и история | `VERSION`, `CHANGELOG.md`, `RELEASE_NOTES.md` в папке проекта |
| Проверка целостности | `bash check.sh` в папке проекта |
| Папка проекта (установщик) | `/Users/user/Documents/deepseek-harness/default-workspace/telegram-life-agent` |

Если папка проекта переехала, в командах подставляй её новый путь.

Важно: `config.json` с токеном — личный файл, не выкладывай его в git и не
пересылай. Права 600 выставлены установщиком автоматически.
